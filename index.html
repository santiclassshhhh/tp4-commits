Objetivo del Proyecto

El objetivo de este proyecto es desarrollar una huerta escolar tecnológica y accesible, integrando conocimientos de agricultura, electrónica y programación.

La huerta cuenta con un sistema de riego automático controlado mediante un ESP32. El sistema utiliza un tanque de agua y una electroválvula para controlar el suministro de agua hacia los cultivos.

Funcionamiento del Sistema de Riego

El ESP32 controla el sistema de riego automático. Cuando llega uno de los días programados, el ESP32 activa la electroválvula. La electroválvula permite el paso del agua desde el tanque hacia la huerta.

    ¿Qué es el ESP32?

    El ESP32 es un microcontrolador desarrollado para proyectos de electrónica, automatización e Internet de las Cosas (IoT). Se caracteriza por ser un dispositivo de bajo costo, bajo consumo de energía y por incorporar conectividad Wi-Fi y Bluetooth.

    En nuestra huerta escolar, el ESP32 funciona como el cerebro del sistema de riego automático. Este dispositivo controla el funcionamiento de la electroválvula según los días de riego programados.

    Cuando corresponde realizar el riego, el ESP32 envía una señal para activar la electroválvula. De esta manera, el agua almacenada en el tanque puede circular hacia los cultivos.

    En el futuro, el sistema podría ampliarse incorporando sensores de humedad del suelo, temperatura o nivel de agua, permitiendo automatizar aún más el funcionamiento de la huerta.

    ESP32: controlador principal del sistema de riego automático.

    ¿Qué es una Electroválvula?

    Una electroválvula es un dispositivo electromecánico que permite controlar el paso de un líquido mediante una señal eléctrica. En este proyecto se utiliza para controlar el flujo de agua destinado al riego de la huerta.

    En nuestro sistema de riego automático, la electroválvula funciona como una llave de paso controlada electrónicamente. Su funcionamiento es controlado por el ESP32, que determina cuándo debe comenzar o finalizar el riego.

    Cuando llega uno de los días programados para el riego, el ESP32 envía una señal eléctrica al sistema de control. Esta señal permite activar la electroválvula y abrir el paso del agua almacenada en el tanque.

    Una vez finalizado el tiempo de riego, el ESP32 deja de enviar la señal correspondiente y la electroválvula cierra el paso del agua. De esta manera, se evita el desperdicio y se controla de forma automática la cantidad de agua utilizada por la huerta.

    La electroválvula es un componente fundamental del sistema, ya que permite automatizar físicamente el flujo de agua sin necesidad de que una persona abra o cierre manualmente una llave.

    Electroválvula: dispositivo encargado de abrir o cerrar el paso del agua hacia la huerta.
